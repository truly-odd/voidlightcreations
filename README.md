# VoidLight Creations

Public static website for Sleep Keeper. The Android application, signing keys,
private journals and tester lists are not in this repository.

GitHub Pages serves the main branch root. Edit index.html, styles.css, app.js,
privacy.html and assets/; commit and push to main to publish. No npm install or
server is needed. .nojekyll keeps deployment static. privacy/index.html preserves
the previous extensionless policy URL; keep its content aligned with privacy.html.

Custom domain: voidlightcreations.com, with www redirecting to the apex after DNS
and the GitHub certificate are configured. Add the CNAME file only as part of the
verified hosting cutover. Google Play privacy URL: https://voidlightcreations.com/privacy.html.

Public support: voidlightcreations@outlook.com.
